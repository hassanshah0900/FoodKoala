# notification-service

**Stack:** NestJS 12 · TypeScript · **Port:** 3007

SMS, WhatsApp, push and email notifications in Urdu and English, triggered by Kafka events.

## Run

```bash
npm install
npm run dev        # http://localhost:3007/healthz
npm test           # Vitest
npm run build
docker build -t foodkoala/notification-service .
```
