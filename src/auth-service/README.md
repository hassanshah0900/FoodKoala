# auth-service

**Stack:** NestJS 12 · TypeScript · **Port:** 3001

Phone number (+92) and OTP login, JWT issuing, roles (customer, vendor, rider, admin).

## Run

```bash
npm install
npm run dev        # http://localhost:3001/healthz
npm test           # Vitest
npm run build
docker build -t foodkoala/auth-service .
```
